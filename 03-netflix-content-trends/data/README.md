# Data

This project uses the **Netflix Movies and TV Shows** dataset.

1. Download it from Kaggle: https://www.kaggle.com/datasets/shivamb/netflix-shows
   (free Kaggle account required — click "Download")
2. Unzip and place `netflix_titles.csv` in this `data/` folder.
3. The notebook expects the path: `data/netflix_titles.csv`

Raw data isn't committed to the repo (kept out via `.gitignore`) — this keeps the repo small and respects Kaggle's dataset terms.
