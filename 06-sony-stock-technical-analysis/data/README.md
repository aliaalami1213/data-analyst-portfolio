# Data

This project uses the **Sony Stock Data** dataset, originally from Kaggle: https://www.kaggle.com/datasets/nilesh2042/sony-stock-data

`sony_stock_data.csv` — daily OHLCV (Open/High/Low/Close/Volume) for Sony (NYSE: SONY), 2014-01-02 to 2026-08-24 — is included in this folder, so `analysis.ipynb` runs as-is — no download needed.
