# Data

This project uses the **IBM HR Analytics Employee Attrition & Performance** dataset.

1. Download it from Kaggle: https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset
   (you'll need a free Kaggle account — click "Download" on that page)
2. Unzip and place `WA_Fn-UseC_-HR-Employee-Attrition.csv` in this `data/` folder.
3. The notebook expects the path: `data/WA_Fn-UseC_-HR-Employee-Attrition.csv`

Raw data isn't committed to the repo (kept out via `.gitignore`) — this keeps the repo small and respects Kaggle's dataset terms.
