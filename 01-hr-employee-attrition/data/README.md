# Data

This project uses the **IBM HR Analytics Employee Attrition & Performance** dataset, originally from Kaggle: https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset

`WA_Fn-UseC_-HR-Employee-Attrition.csv` is included in this folder (it's a small, public, fictional dataset), so `analysis.ipynb` runs as-is — no download needed.
