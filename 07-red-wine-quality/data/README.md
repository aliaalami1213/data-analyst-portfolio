# Data

This project uses the **Red Wine Quality** dataset (Cortez et al., 2009), from Kaggle/UCI: https://www.kaggle.com/datasets/uciml/red-wine-quality-cortez-et-al-2009

`winequality-red.csv` — 1,599 Portuguese "Vinho Verde" red wines with 11 physicochemical inputs and a 0–10 expert quality score — is included in this folder, so `analysis.ipynb` runs as-is — no download needed.
