# Data

This project uses the **E-Commerce Customer Segmentation Dataset 2026**, originally from Kaggle: https://www.kaggle.com/datasets/datascikhan/e-commerce-customer-segmentation-2026 (CC0: Public Domain)

`E-commerce_Customer_Segmentation_2026.csv` (50,000 rows, 53 columns, ~20 MB) is included in this folder, so `analysis.ipynb` runs as-is — no download needed.
